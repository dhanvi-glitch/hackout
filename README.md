# OptiGrid-AI

OptiGrid-AI is an intelligent grid management and optimization platform developed for hackathons.

## Repository Structure

```text
OptiGrid-AI/
├── frontend/        # Web dashboard & user interface
├── backend/         # Server API & service integrations
├── optimization/    # AI/ML & grid optimization models
├── data/            # Datasets, schemas & sample inputs
└── docs/            # Project documentation & specs
```

## Team Workflow

This repository is structured to allow four team members to work independently across frontend, backend, optimization, and data pipelines.
